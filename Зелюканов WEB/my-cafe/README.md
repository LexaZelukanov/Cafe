# Crumble Cafe — учебный проект на Webpack

## Что это такое

Это сайт маленького кафе. На странице три вкладки:

- **Главная** — приветствие.
- **Меню** — список блюд с картинками и ценами.
- **Контакты** — адрес, телефон, кнопка брони и форма обратной связи.

Вкладки переключаются **без перезагрузки страницы**. Всё содержимое
создаётся через JavaScript, а не пишется руками в HTML.

---

## Что сделали (по-простому)

1. **Собрали проект на Webpack.** Webpack — это программа, которая берёт
   много наших файлов (JS, CSS, картинки, JSON) и складывает их в одну
   папку `dist/`, чтобы сайт работал в браузере.

2. **Сделали пустой HTML.** В `src/index.html` лежит только `<div id="content"></div>`.
   Больше ничего. Всё остальное рисует JS.

3. **Разбили код на модули.** Каждая вкладка — отдельный файл:
   - `home.js` — главная,
   - `menu.js` — меню,
   - `contact.js` — контакты.

4. **Сделали навигацию.** В `index.js` есть кнопки «Главная / Меню / Контакты».
   При клике старый контент стирается, загружается новый. Страница не
   перезагружается.

5. **Добавили стили.** В `style.css` — цвета, шрифты, красивые кнопки,
   анимация появления контента. Шрифт заголовков подключается из Google Fonts.

6. **Меню берём из JSON.** Список блюд лежит в `src/menu-data.json`.
   В `menu.js` он читается и превращается в карточки с картинками.

7. **Картинки блюд** лежат в `src/images/`. Webpack сам их обрабатывает
   и копирует в `dist/`.

8. **Счётчик посещений меню.** Каждый раз, когда открываешь «Меню»,
   счётчик увеличивается на 1. Число хранится в `localStorage` — то есть
   не пропадает после перезагрузки страницы.

9. **Форма обратной связи с проверкой.** Если имя короче 2 букв, email
   неправильный или сообщение пустое — поле краснеет и появляется ошибка.
   Если всё верно — всплывает `alert('Спасибо, <имя>!')` и форма очищается.

10. **Кнопка «Забронировать столик»** — просто показывает `alert`.

## Как запустить (пошагово)

### Шаг 1. Открыть папку проекта

Откройте VS Code и через меню **File → Open Folder…** выберите папку
`my-cafe` (там, где лежит `package.json`).

### Шаг 2. Открыть терминал

В VS Code сверху меню **Terminal → New Terminal**.
Внизу появится чёрное окно — это терминал. Убедитесь, что путь в нём
заканчивается на `my-cafe` (например, `...\my-cafe>`).

### Шаг 3. Установить зависимости (делается один раз)

В терминале напишите и нажмите Enter:

```bash
npm install
```

Ждите. Появится папка `node_modules` — не пугайтесь, это нормально.
Это скачались нужные программы (Webpack и т.д.). Делать это нужно
**только один раз** после скачивания проекта.

### Шаг 4. Запустить сайт

В терминале:

```bash
npm start
```

Через 5–10 секунд:

- откроется браузер по адресу **http://localhost:8080**;
- в терминале появится надпись `Compiled successfully` (или похожая).

Сайт работает. Кликайте вкладки, проверяйте всё.

### Шаг 5. Остановить сервер

В терминале нажмите **Ctrl + C** (один раз). Сервер выключится.
